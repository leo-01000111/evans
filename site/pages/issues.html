Known bugs

Each is on the roadmap, with what fixing it involves.

  • true(n) and false(m,n) fail with "Index exceeds the number of array elements". Use logical(zeros(m,n)) until it is fixed.
  • Growing an array with a(end+1) = v in a loop is slow, because each step makes a new array. Pre-allocate (a = zeros(1,n)) and fill it, which is fast.

Not supported yet

These stop with an error that names them rather than giving a wrong answer. The MATLAB compatibility page has the full list.

  • Language: varargout in a function file; arrays of classdef objects, subsref/subsasgn and +package folders; categorical arrays and time zones.
  • Data: the old Excel format (.xls) and .ods. Save as .xlsx, which Evans reads and writes.
  • Plotting: graphics handles, as in h = plot(...) and set(h, ...).
  • Simulink: opening .slx or .mdl files, buses, masks and block libraries, physical (Simscape-style) modelling, and a subsystem that is both enabled and triggered.
  • Symbolic maths: symbolic functions such as syms y(t), and so dsolve.
  • Platforms: no Linux build yet, and the builds are not signed by Microsoft or Apple, so Windows and macOS warn the first time. See the install notes.

Report an issue

A bug, a MATLAB script that does not run, a missing command, or an idea. The more of the steps you can give, the faster it gets fixed. Leave an email if you would like a reply. You can also open an issue on GitHub.

Reports are sent by email through Formspree.
