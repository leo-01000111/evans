# hex2dec

Convert hexadecimal digits, as text, to a number.

## Syntax

    d = hex2dec(str)

## Description

`hex2dec('FF')` is 255; upper or lower case. A char matrix or cell gives one number per row.

## Example

```matlab
hex2dec('FF')
hex2dec('1a')
```
