# isfloat

True for single and double.

## Syntax

    tf = isfloat(A)

## Description

`isfloat(A)` is true for `double` and `single` values and false for integers, logicals and text.

## Example

```matlab
isfloat(3)
isfloat(single(3))
isfloat(int8(3))
```
