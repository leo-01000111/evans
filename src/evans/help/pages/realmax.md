# realmax

Largest floating-point number.

## Syntax

    v = realmax
    v = realmax('single')

## Description

The largest finite double, about 1.7977e+308, or the largest `single`, about 3.4028e+38.

## Example

```matlab
realmax
realmax('single')
```
