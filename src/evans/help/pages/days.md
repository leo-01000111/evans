# days

A duration in days, or a duration as a number of days.

## Syntax

    d = days(x)
    x = days(d)

## Description

See `seconds`. For a step of whole calendar days, see `caldays`.

## Example

```matlab
days(2) + hours(12)
days(hours(36))
```
