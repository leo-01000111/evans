# realmin

Smallest normalised floating-point number.

## Syntax

    v = realmin
    v = realmin('single')

## Description

The smallest positive normalised double, about 2.2251e-308, or `single`, about 1.1755e-38.

## Example

```matlab
realmin
realmin('single')
```
