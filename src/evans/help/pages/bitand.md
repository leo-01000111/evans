# bitand

Bitwise AND.

## Syntax

    C = bitand(A, B)

## Description

Compares the bits of two non-negative integers. Integer-class inputs give that class; doubles must hold whole numbers up to 2^53.

## Example

```matlab
bitand(12, 10)
bitand(uint8(255), uint8(15))
```
