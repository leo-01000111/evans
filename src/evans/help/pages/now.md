# now

The current date and time as a serial date number.

## Syntax

    t = now

## Description

Days since the start of year 0, with the time of day as the fraction, as [datenum](datenum) counts them. [datestr](datestr) shows one as text.

## Example

```matlab
datestr(now)
```
