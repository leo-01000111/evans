# base2dec

Convert digits in any base, as text, to a number.

## Syntax

    d = base2dec(str, base)

## Description

`base` is 2 to 36. `base2dec('ZZ', 36)` is 1295.

## Example

```matlab
base2dec('101', 3)
base2dec('ZZ', 36)
```
