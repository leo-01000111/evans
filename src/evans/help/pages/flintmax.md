# flintmax

Largest consecutive integer in floating point.

## Syntax

    v = flintmax
    v = flintmax('single')

## Description

Above `flintmax` not every integer can be stored: 2^53 for double and 2^24 for single.

## Example

```matlab
flintmax
flintmax('single')
```
