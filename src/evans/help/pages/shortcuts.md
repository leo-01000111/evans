# Keyboard shortcuts

Every shortcut in the menus, and the few keys that belong to one widget. Press Ctrl+/ for this list in a window, and Ctrl+K or Ctrl+Shift+P to search every action by name. On a Mac, Ctrl is the Command key.

## File

- Ctrl+Shift+C: Copy analysis report
- Ctrl+Shift+E: Export pane as PNG…
- Ctrl+N: New
- Ctrl+O: Open…
- Ctrl+Q: Quit
- Ctrl+S: Save
- Ctrl+Shift+S: Save as…

## Edit

- Ctrl+,: Preferences…
- Ctrl+Y / Ctrl+Shift+Z: Redo
- Ctrl+Z: Undo

## View

- Ctrl+1: Analyse
- Ctrl+B: Block palette
- Ctrl+Shift+A: Cedric
- Ctrl+3: Console
- Ctrl+2: Model
- Ctrl+K / Ctrl+Shift+P: Search…
- Ctrl+\: Side panel

## Help

- F1: Documentation
- Ctrl+/: Keyboard shortcuts

## Model

- Ctrl+R: Run simulation

## Anywhere

- Ctrl+`: Go to the command window

## Model canvas

- Double-click: Add a block by name (or just start typing)
- Delete: Delete the selected blocks and lines
- Esc: Leave the subsystem, or cancel what is in hand
- Ctrl+wheel: Zoom the diagram

## Command window

- Up / Down: Walk through the commands typed before
- Tab: Complete the name being typed
- Ctrl+Space: Show every completion here

## Script editor

- F5: Run the script, or continue when paused
- F10: Run the paused line
- F11: Step into the call on the paused line
