# nthroot

Real n-th root.

## Syntax

    y = nthroot(x, n)

## Description

The real n-th root of `x`, elementwise: `nthroot(-27, 3)` is −3, where `(-27)^(1/3)` is complex. A negative `x` needs an odd integer `n`.

## Example

```matlab
nthroot(-27, 3)
(-27)^(1/3)
```
