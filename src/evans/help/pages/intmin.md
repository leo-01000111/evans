# intmin

Smallest value of an integer class.

## Syntax

    v = intmin
    v = intmin(classname)
    v = intmin(A)

## Description

`intmin('int8')` is -128. With no argument the class is `int32`.

## Example

```matlab
intmin('int8')
intmin('uint8')
```
